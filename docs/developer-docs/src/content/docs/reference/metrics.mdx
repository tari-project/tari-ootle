---
title: Metrics
description: Prometheus metrics exported by the validator node and the indexer, grouped by subsystem, for operators building dashboards and alerts.
---

The validator node and the indexer export Prometheus metrics in OpenMetrics text format. Counters carry a `_total`
suffix. Every series is labelled with `app` and the node's `public_key`.

## Common

### Scraping

| App            | Endpoint                                                             | Config key                                 | `app` label     |
| -------------- | -------------------------------------------------------------------- | ------------------------------------------ | --------------- |
| Validator node | `GET /_metrics` on a dedicated listener (default `127.0.0.1:18201`)  | `validator_node.metrics_listener_address`  | `ValidatorNode` |
| Indexer        | `GET /_metrics` on a dedicated listener (default `127.0.0.1:18302`)  | `indexer.metrics_listen_address`           | `OotleIndexer`  |

Unsetting the listener address disables the endpoint.

| `network_fee_volume_microtari`               | gauge | Fees paid, summed over stored receipts.                 |
| `network_receipt_exhaust_burned_microtari`   | gauge | Exhaust burned, summed over stored receipts.            |
| `network_transaction_receipt_count`          | gauge | Transaction receipts stored.                            |
| `network_validator_claimable_fees_microtari` | gauge | Leader fees in validator fee pools, not yet claimed.    |
| `network_exhaust_rate_bps`                   | gauge | Exhaust burn rate in basis points at the current epoch. |
